# First session capture

1. Record five fresh first sessions per device profile, from the profile-defined starting point through its end task.
2. Record time to first action and goal, first reward reached, required controls taught, gates, load size, crash outcome, frame-time samples, next goal and actions to restart.
3. Derive the firstAction, firstWin, clarity, friction, stability and return groups from those sessions. Record measuredCases and the matching artifact for each group or line.
4. Anything you could not capture stays out of the pack. It grades U, which is honest.
