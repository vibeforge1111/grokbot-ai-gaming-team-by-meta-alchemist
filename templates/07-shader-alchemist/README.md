## Start here

**What it does.** Grade shader compile, backend parity, and GPU budgets for any engine, then write a local evidence pack and ticket drafts.

**When to use it.** When you have shader graphs or materials to ship, and you want a first read of compile, backend parity, or GPU budget.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `shader-alchemist-lens-engine` first, then `shader-alchemist-getting-started`. Then save the rest: `shader-graph-and-compile-check`, `cross-backend-shader-parity-gate`, `gpu-budget-and-shader-safety`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the shader-alchemist-getting-started skill. Ask me one question at a time. My game is <name or code name, genre, engine, platforms, shader system>. The build to grade is <commit and build id>. Evidence comes from <compile logs, a parity report, GPU timings, or a manual capture>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
