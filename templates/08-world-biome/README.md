## Start here

**What it does.** Grade seeded world generation, traversal, and encounter placement for any engine, then write a local evidence pack and ticket drafts.

**When to use it.** When a seeded world or biome generator exists, and you want a first read of repeatability, traversal, or encounter placement.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `world-biome-lens-engine` first, then `world-biome-getting-started`. Then save the rest: `seeded-world-repeatability-check`, `traversal-and-cover-audit`, `encounter-placement-and-world-safety`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the world-biome-getting-started skill. Ask me one question at a time. My game is <name or code name, genre, engine, platforms, generation method>. The build to grade is <commit and build id>. Evidence comes from <seeded exports, a nav report, an encounter report, or a manual capture>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
