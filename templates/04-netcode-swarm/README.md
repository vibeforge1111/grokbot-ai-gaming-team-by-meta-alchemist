## Start here

**What it does.** Grade prediction, authority, desync, and bot-swarm load for any multiplayer game, then write a local evidence pack and ticket drafts.

**When to use it.** When a multiplayer build can be joined, and you want a first read of prediction, authority, desync, or bot-swarm load.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `netcode-swarm-lens-engine` first, then `netcode-swarm-getting-started`. Then save the rest: `authoritative-prediction-and-interpolation-audit`, `headless-bot-swarm-load-tester`, `netcode-desync-and-soak-proof`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the netcode-swarm-getting-started skill. Ask me one question at a time. My game is <name or code name, genre, engine, platforms, netcode model>. The build to grade is <commit and build id>. Evidence comes from <session traces, a soak log, a bot swarm I already have, or a manual capture>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
