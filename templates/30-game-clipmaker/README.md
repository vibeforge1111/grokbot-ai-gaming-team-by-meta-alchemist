## Start here

**What it does.** Grade peak-moment detection and a local clip list from gameplay recordings, then write ticket drafts. Trailer Director still covers trailer-shaped cuts; this bot finds in-match moments.

**When to use it.** When you have gameplay recordings and want a first read of peak moments, timecodes, or a local clip list, rather than a trailer cut.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `game-clipmaker-lens-engine` first, then `game-clipmaker-getting-started`. Then save the rest: `peak-moment-and-timecode-pass`, `clip-clarity-and-rights-check`, `clip-list-safety-and-identity`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the game-clipmaker-getting-started skill. Ask me one question at a time. My game is <name or code name, genre, engine, platforms>. The build and recordings to grade are <ids>. Evidence comes from <gameplay recordings, a moment log with timecodes, or a manual list>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
