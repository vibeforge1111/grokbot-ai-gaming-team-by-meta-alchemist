## Start here

**What it does.** Grade cinematic continuity, shot coverage, and a local export plan for any game, then write a work plan and ticket drafts. Trailer Director still covers trailer cuts; this bot plans the shoot or stills sequence.

**When to use it.** When you are planning a cinematic, a stills sequence, or a shoot, and you want a first read of continuity, coverage, or a local export plan.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `studio-director-lens-engine` first, then `studio-director-getting-started`. Then save the rest: `continuity-and-coverage-board`, `runtime-and-rights-check`, `studio-export-plan-and-safety`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the studio-director-getting-started skill. Ask me one question at a time. My game or cinematic is <name or code name, genre, engine, delivery format>. The build or shoot to grade is <id>. Evidence comes from <a shot list, continuity notes, rights notes, or a clip list I already have>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
