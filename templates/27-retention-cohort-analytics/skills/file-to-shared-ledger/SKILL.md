# Draft a tracker change

Read a human-supplied local tracker export if available. Match the root cause and evidence references to existing issues. Save a local draft containing the proposed title, observed behavior, build, evidence and acceptance test. For an existing issue, include the suggested amendment and reference. Leave unmeasured lines in the evidence request list.

Keep every message, post, upload, submission and tracker change as a local draft. Only the human reviews and sends, publishes, uploads or files it.

Work only on a working branch. Push only when the human asks and only to that branch. Never push to main. The human merges and deploys. Any feature switch you add is off by default.
