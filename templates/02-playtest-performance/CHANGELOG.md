## [Unreleased]

### Added

- `engine/build-pack.mjs` writes a pack and a lens-kit 1.3.1 producer receipt from owner-supplied journey and frame files, or by stamping an existing pack. This template stays preview until it has worked examples from at least two real games and a live capture grade.

## [0.1.0] - 2026-11-26

### Added

- First preview of Playtest and Performance Director. It grades opening and core journeys, planned scenarios, stability, owner-set frame-time budgets, and coverage. Skills cover getting started, frame pacing (GPU counters optional), and scripted browser playtests when the game runs in a browser. The README lists the remaining ship blockers.
