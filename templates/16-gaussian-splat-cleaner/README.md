## Start here

**What it does.** Grade splat cleanup, continuity, and navigation proxies from owner-supplied captures, then write a local evidence pack and ticket drafts.

**When to use it.** When you have a Gaussian splat or similar 3D capture to clean, and you want a first read of floaters, seams, budget, or walkable proxies.

**Setup.** The Grok Bot share link is coming soon, so there is no link to open yet. Paste each `SKILL.md` from `skills/` into a Grok Bot chat and say: "Save this as a skill." Save `splat-cleaner-lens-engine` first, then `splat-cleaner-getting-started`. Then save the rest: `floater-and-seam-cleanup-review`, `splat-proxy-and-budget-check`, `splat-source-safety-and-identity`. Paste each fact in [MEMORY.md](MEMORY.md) and say: "Remember this for this project." The same files work in Claude, ChatGPT, Codex, Cursor, Gemini, or any other chat. See [INSTALL.md](../../INSTALL.md). Step by step: [HOW-TO-USE.md](HOW-TO-USE.md).

**First prompt.** Copy this into the chat after the skills are saved. Fill in the angle brackets.

```
Run the splat-cleaner-getting-started skill. Ask me one question at a time. My scene is <name or code name, capture source, engine or viewer>. The build or capture to grade is <id>. Evidence comes from <a before and after splat, a cleanup report, a proxy or nav report, or a manual review>.
```

**Example output.** From this folder:

```
node engine/lens.mjs fixtures/good-pack.json
```

The synthetic worked example prints verdict **PASS** and grade **100/100**, with every line measured. `fixtures/good-pack.json` is not a measurement of a real game.
